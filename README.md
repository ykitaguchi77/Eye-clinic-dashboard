# Eye-clinic-dashboard

有床眼科クリニック向けの入院・病床管理と収益見込みのダッシュボードです。Googleスプレッドシートにバインドした Apps Script のウェブアプリとして動きます。

## 機能（v0.1）

- 術式を選ぶと空きベッドを自動で割り当てる病床カレンダー（2週間表示、仮押さえ／確定）
- 月ごとの売上・利益見込みと、空き手術枠の埋まり率を使った試算（管理権限のみ）
- 管理・入力・閲覧の3段階の権限と、全操作の変更履歴
- 任意で Googleカレンダーへ自動反映

| ファイル | 内容 |

## セットアップ

詳しくは `セットアップ手順.md` を参照してください。

**方法A：ブラウザだけ（Node.js 不要）** — 施設のPCなど、ソフトをインストールできない環境向け。

1. スプレッドシートを作り、「拡張機能」→「Apps Script」を開く
2. `コード.gs` の中身を `gas/Code.gs` の内容に置き換えて保存
3. 「デプロイ」→「新しいデプロイ」→ ウェブアプリ（実行：自分／アクセス：組織内の全員）
4. 表示されたURLをまず自分で開く（シートは自動で作られる）

**方法B：コマンド（Node.js）** — Apps Script API をオンにしたうえで：

```
git clone https://github.com/ykitaguchi77/Eye-clinic-dashboard.git
cd Eye-clinic-dashboard
node setup.mjs
```

コードを更新したときは、同じフォルダで `git pull` してから `node setup.mjs` を再実行すると、同じURLのまま新しい版に切り替わります。

## 設定（マスタ）の変更方法

術式・ベッド数・単価などは、コードを触らずに**スプレッドシートのシートを直接編集**して変えます。シートは初回アクセス時に自動で作られます（初期値は仮のものです）。

- 変更は保存した時点で反映されます。ダッシュボードを開いている人は、ページを再読み込みすると新しい設定になります。
- 1行目の見出しと、シート名は変えないでください（プログラムが名前で読み取っています）。
- 「有効」列はチェックボックスです。行を追加したときは、その列に `TRUE` と入力するか、「挿入」→「チェックボックス」でチェックボックスを入れてください。

### 術式マスタ（術式パターンと単価）

入力画面の術式ボタンは、このシートの「有効」な行がそのまま並びます。

| 列 | 内容 | 例 |
|---|---|---|
| 術式コード | 行ごとに重複しない英数字。予約台帳はこのコードで術式を参照する | `CAT2` |
| 表示名 | ボタンやカレンダーに出る名前 | `白内障 両眼` |
| 入院パターン | ボタンに出る説明（表示のみ） | `1泊2日` |
| 泊数 | **ベッドを使う期間を決める数字**。入院日から泊数日後の退院日までベッドを使用中とみなす（1泊2日なら `1`） | `1` |
| 眼数 | 件数の「◯眼」集計に使う（片眼 `1`、両眼 `2`） | `2` |
| カテゴリ | 色分けと収益内訳の分類。`白内障` `眼瞼` `涙道` `網膜硝子体` には専用の色がつき、それ以外はグレー | `白内障` |
| 単価(円) | 1件あたりの売上見込み（円、税・カンマなしの数字）。手術料・入院料（泊数分）・材料費などを含めた1入院あたりの総額を入れるのがおすすめ | `380000` |
| 有効 | チェックを外すと入力画面のボタンから消える | ☑ |

- **術式を増やす**：行を追加して、上の8列を埋める。同じ術式で入院日数だけ違う場合（白内障両眼の1泊2日と2泊3日など）は、コードを分けて別の行にする。
- **術式をやめる**：行は消さず、「有効」のチェックを外す。行を消すと、その術式で入っている予約の泊数と単価が0として扱われてしまいます。
- **泊数・単価を変える**：その術式の既存の予約にもさかのぼって反映されます（カレンダーの帯の長さと収益見込みが変わる）。過去と今後で条件を分けたい場合は、新しいコードの行を作り、古い行の「有効」を外してください。
- 単価は管理権限の人の画面にだけ表示されます。単価が0円の術式があると、収益見込み画面に注意が出ます。

### ベッドマスタ（ベッド数）

| 列 | 内容 | 例 |
|---|---|---|
| ベッド番号 | 重複しない整数。自動割り当ては番号の小さい順に空きを探す | `1` |
| 名称 | カレンダーの行に出る名前 | `ベッド1`、`個室A` |
| 有効 | チェックを外すとカレンダーと自動割り当ての対象から外れる | ☑ |

- **床数を増やす**：行を追加する（番号は続きの数字）。
- **床数を減らす・休床する**：行は消さず「有効」のチェックを外す。そのベッドに入っている予約はカレンダーに表示されなくなるので、**先に別のベッドへ移してから**外してください。
- 病床稼働率は「有効」なベッドの数を分母にして計算されます。

### 手術枠マスタ（収益シミュレーション用）

| 列 | 内容 | 例 |
|---|---|---|
| 曜日 | `月` `火` `水` `木` `金` `土` `日`（この7行は消さない・書き換えない） | `水` |
| 手術枠数 | その曜日に受けられる入院手術の件数。手術がない曜日は `0` | `4` |

- 収益見込み画面の「残りの手術枠 × 埋まり率 × 平均単価」の計算だけに使います。予約の登録を枠数で制限するものではありません（登録の上限はベッドの空きで決まります）。
- すべて0のままだと、空き枠からの上乗せは計算されません。

### ユーザー（使う人と権限）

| 列 | 内容 | 例 |
|---|---|---|
| メールアドレス | 組織の Google アカウントのアドレス | `nurse@example.com` |
| 氏名 | 画面右上に表示 | `看護師A` |
| 権限 | `管理`：すべての画面と操作（収益見込みと単価を含む）／`入力`：病床カレンダーの閲覧と予約の登録・変更・取消／`閲覧`：病床カレンダーの閲覧のみ | `入力` |

- ここに登録されていない人は、URLを開いても「利用権限がありません」と表示されます。
- 最初の行には、ウェブアプリを公開した人が管理者として自動で入っています。

### 設定

| 項目 | 内容 |
|---|---|
| 施設名 | 画面上部に表示（空欄でも可） |
| 原価率 | 利益見込みの初期値。`0.55` なら55%（画面のスライダーで一時的に変えられる） |
| カレンダーID | 入れると、登録・変更・取消が Googleカレンダーにも終日予定として反映される。空欄なら反映しない。IDは Googleカレンダーの「設定と共有」→「カレンダーの統合」に表示される |

### 直接編集しないシート

- **予約台帳**：予約の本体。登録・変更・取消はダッシュボードから行ってください（直接書き換えると二重予約の確認や変更履歴が働きません）。
- **変更履歴**：誰がいつ何をしたかの記録。

## 開発メモ

編集するのは `src/` のファイルです。編集したら `node tools/build-gas.mjs` で `gas/Code.gs` を作り直し、両方をコミットしてください（`node tools/build-gas.mjs --check` でずれを確認できます）。

## 注意

このリポジトリにはコードだけを置きます。患者IDなどの実データ（スプレッドシートの中身）はコミットしないでください。
