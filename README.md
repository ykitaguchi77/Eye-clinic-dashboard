# Eye-clinic-dashboard

有床眼科クリニック向けの入院・病床管理と収益見込みのダッシュボードです。Googleスプレッドシートにバインドした Apps Script のウェブアプリとして動きます。

## ファイル

| ファイル | 内容 |
|---|---|
| `Code.gs` | サーバ側スクリプト（初期設定、予約の登録・変更・取消、収益集計、Googleカレンダー反映） |
| `Index.html` | 画面（病床カレンダー、予約入力、収益見込み） |
| `appsscript.json` | マニフェスト（組織内限定のウェブアプリとして公開） |
| `セットアップ手順.md` | スプレッドシートへの貼り付けから公開までの手順 |

## 機能（v0.1）

- 術式を選ぶと空きベッドを自動で割り当てる病床カレンダー（2週間表示、仮押さえ／確定）
- 月ごとの売上・利益見込みと、空き手術枠の埋まり率を使った試算（管理権限のみ）
- 管理・入力・閲覧の3段階の権限と、全操作の変更履歴
- 任意で Googleカレンダーへ自動反映

## 注意

このリポジトリにはコードだけを置きます。患者IDなどの実データ（スプレッドシートの中身）はコミットしないでください。
