# Eye-clinic-dashboard

有床眼科クリニック向けの、入院・手術・発注の管理ツールです。iPad や PC からタップ中心で入力し、ダッシュボードで確認して、収益表・支出・発注書を Excel で出力します。Googleスプレッドシートにバインドした Apps Script のウェブアプリとして動きます。

## 機能（v0.3）

- **入院・手術**：入院／外来（日帰り）、術式、眼（右・左・両眼）、執刀医をタップで登録。入院は空きベッドを自動で割り当て、病床カレンダーに表示
- **発注**：発注先 → 区分 → 品目の「＋／−」で数量を入れて登録。品目を持たない発注先（レンズなど）は金額だけ入力。過去の発注の修正・取消
- **収益・支出**（管理者）：月ごとの入院人数、入院手術・外来手術の眼数と収入、執刀医別の件数、発注先ごとの支出、残りの手術枠からの見込み
- **Excel 出力**
  - 発注書（1回の発注ぶん。FAX・メール用。注文数0の品目も載せる版も選べる）
  - 月次レポート：収益表／コスト計算用／支出合計／発注先ごとの発注集計（週ごとの金額）
- 権限は Google の共有設定で決まる（個人の Google アカウントでも使える）。全操作の変更履歴。任意で Googleカレンダーへ自動反映

## 権限（Google の共有で決まる）

アプリは「アクセスしているユーザーとして実行」で動き、使う人それぞれの Google アカウントでログインします。権限はユーザー一覧ではなく、**スプレッドシートの共有設定**で決まります。

| 権限 | 決まり方 | できること |
|---|---|---|
| 管理 | 管理者用スプレッドシート（下記）を共有されている人 | すべて（収益・支出、月次レポート、単価の確認） |
| 入力 | このスプレッドシートを「編集者」として共有されている人 | 入院・手術と発注の登録、発注書の出力（金額のうち収益関係は受け取らない） |
| 閲覧 | このスプレッドシートを「閲覧者」として共有されている人 | 病床カレンダーと手術一覧を見るだけ |

- データは2つのスプレッドシートに分かれています。
  - **このスプレッドシート**（スタッフと共有）：台帳・発注・品目・術式などのマスタ
  - **管理者用スプレッドシート**（管理者だけと共有）：収益区分マスタ・術式単価（請求額・コスト）・入院1人あたり収入。初回に自動で作られ、同じフォルダに置かれます
- マスタのシートは持ち主だけが編集できるように自動で保護されます。スタッフは画面から台帳に書き込むだけです。
- 共有をやめれば、その人は使えなくなります（反映まで最大5分）。
- 各自、最初に開いたときに「このアプリは Google で確認されていません」と出ます。「詳細」→「（安全ではないページ）に移動」→「許可」で進めます（1回だけ）。

## セットアップ

詳しくは `セットアップ手順.md` を参照してください。

**方法A：ブラウザだけ（Node.js 不要）** — 施設のPCなど、ソフトをインストールできない環境向け。

1. スプレッドシートを作り、「拡張機能」→「Apps Script」を開く
2. `コード.gs` の中身を `gas/Code.gs` の内容に置き換えて保存
3. 「デプロイ」→「新しいデプロイ」→ ウェブアプリ（次のユーザーとして実行：**ウェブアプリにアクセスしているユーザー**／アクセスできるユーザー：**Google アカウントを持つ全員**）
4. 表示されたURLを**持ち主が最初に**開く（シートと管理者用スプレッドシートが自動で作られる）
5. 各マスタを入力し、使う人にスプレッドシートを共有する（上の「権限」）

**方法B：コマンド（Node.js）** — Apps Script API をオンにしたうえで：

```
git clone https://github.com/ykitaguchi77/Eye-clinic-dashboard.git
cd Eye-clinic-dashboard
node setup.mjs
```

コードを更新したときは、同じフォルダで `git pull` してから `node setup.mjs` を再実行すると、同じURLのまま新しい版に切り替わります。

> v0.1・v0.2 で作ったスプレッドシートはシートの構成と公開設定が違うため、そのままでは使えません。新しいスプレッドシートで作り直してください（見出しが違うシートがあると、画面にその旨が表示されます）。

## 集計のルール

- **収益表**：手術日がその月の記録を、術式マスタの「収益区分」ごとに集計します。収入＝眼数×1眼あたり収入（両眼は2眼）。入院は、入院日がその月の人数×「入院1人あたり収入」。外来手術の合計は外来の行だけを足します。
- **手術合計（トリプル分解分）**：手術の眼数に、収益区分マスタで「トリプル」にした区分の眼数をもう一度足したもの。
- **手術ディスポ代**：その日の手術の、術式マスタの「コスト」の合計（片眼・両眼で別の金額を使う）。
- **支出合計**：発注日ごと・発注先ごとの発注金額＋手術ディスポ代。「手術コスト合計」は「手術コストに含める」発注先（レンズなど）＋手術ディスポ代。
- **発注集計の週**：1週目＝1〜7日、2週目＝8〜14日、3週目＝15〜21日、4週目＝22〜28日、5週目＝29日〜末日。
- 取り消した記録・発注は集計に含めません。仮押さえは含めます（画面に件数を表示）。

## 設定（マスタ）の変更方法

術式・単価・医師・ベッド・品目などは、コードを触らずに**スプレッドシートのシートを直接編集**して変えます。シートは初回アクセス時に自動で作られます（初期値は仮のものです）。マスタのシートは持ち主だけが編集できます（他の人に編集を任せたいときは、そのシートの「シートと範囲を保護」で編集者を追加）。

- 変更は保存した時点で反映されます。ダッシュボードを開いている人は、ページを再読み込みすると新しい設定になります。
- 1行目の見出しと、シート名は変えないでください（プログラムが名前で読み取っています）。
- 「有効」などの TRUE/FALSE の列はチェックボックスです。行を追加したときは `TRUE` と入力するか、チェックを入れてください。
- 既存の一覧を貼り付けるときは、各シートの **A2 から** 貼り付けます（最初から入っているサンプル行は先に消す）。

### 術式マスタ

入力画面の術式ボタンは、このシートの「有効」な行が「色分け」ごとにまとまって並びます。金額はここには入れず、管理者用スプレッドシートの「術式単価」に入れます。

| 列 | 内容 | 例 |
|---|---|---|
| 術式コード | 行ごとに重複しない英数字。記録や術式単価はこのコードで術式を参照する | `CAT` |
| 表示名 | ボタンや一覧に出る名前 | `白内障（PEA+IOL）` |
| 収益区分 | 収益表で集計する区分。**収益区分マスタの区分名と同じ文字**にする | `白内障` |
| 標準泊数 | 入院で登録するときの泊数の初期値。0なら外来が初期値になる | `1` |
| 色分け | ボタンとカレンダーの色。`白内障` `網膜硝子体` `緑内障` `眼瞼` `涙道` には専用の色、それ以外はグレー | `白内障` |
| 有効 | チェックを外すと入力画面から消える | ☑ |

- **術式をやめる**：行は消さずに「有効」を外す（消すと、その術式の記録の集計ができなくなります）。
- 泊数は記録ごとに保存されるので、標準泊数を変えても過去の記録は変わりません。

### 術式単価（管理者用スプレッドシート）

| 列 | 内容 | 例 |
|---|---|---|
| 術式コード | 術式マスタのコードと同じ | `CAT` |
| 請求額(片眼)／(両眼) | 1件あたりの請求額。両眼が空欄なら片眼の2倍 | `140000` |
| コスト(片眼)／(両眼) | 1件あたりの材料などのコスト（手術ディスポ代になる）。両眼が空欄なら片眼の2倍 | `65000` |

ここにない術式は、請求額・コストを0として集計します。単価を変えると、その術式の過去の記録の集計にも反映されます。

### 収益区分マスタ（管理者用スプレッドシート）

収益表の行になる区分と、1眼あたり収入です。

| 列 | 内容 | 例 |
|---|---|---|
| 区分名 | 収益表の区分 | `白内障` |
| 1眼あたり収入(円) | 収益表の「1眼あたり収入」 | `75000` |
| トリプル | 「手術合計（トリプル分解分）」で2件として数える区分 | ☑ |
| 入院表に常に表示／外来表に常に表示 | 手術がない月も収益表に0の行を出す | ☑ |
| 有効 | | ☑ |

術式マスタの収益区分がこのシートにないときは、収入0で集計し、画面に注意を出します。

### 医師マスタ

| 列 | 内容 |
|---|---|
| 氏名 | 執刀医のボタンと、収益表の医師別の列に出る名前（例：`○○先生`） |
| 有効 | 外すとボタンから消える（過去の記録の集計には残る） |

### ベッドマスタ

| 列 | 内容 | 例 |
|---|---|---|
| ベッド番号 | 重複しない整数。自動割り当ては番号の小さい順に空きを探す | `1` |
| 名称 | カレンダーの行に出る名前 | `ベッド1`、`個室A` |
| 有効 | 外すとカレンダーと自動割り当ての対象から外れる | ☑ |

休床にする前に、そのベッドの入院を別のベッドへ移してください（外したベッドの入院はカレンダーに表示されなくなります）。

### 手術枠マスタ

| 列 | 内容 | 例 |
|---|---|---|
| 曜日 | `月`〜`日`（この7行は消さない・書き換えない） | `水` |
| 手術枠数 | その曜日に受けられる手術の件数 | `8` |

収益・支出画面の見込み（残りの手術枠×埋まり率×1件あたり平均収入）だけに使います。登録の上限にはなりません。

### 発注先マスタ

| 列 | 内容 | 例 |
|---|---|---|
| 発注先 | 発注画面のボタンと、支出合計の列名 | `○○医療器` |
| 発注書の宛名 | 発注書の「○○ 御中」。空欄なら発注先の名前 | `○○医療器株式会社` |
| 入力方法 | `品目`：品目マスタから数量を入れる／`金額`：金額だけ入れる | `品目` |
| 手術コストに含める | 支出合計の「手術コスト合計」に含める（レンズなど） | ☐ |
| 有効 | | ☑ |

### 品目マスタ

| 列 | 内容 | 例 |
|---|---|---|
| 品目ID | 空欄のままでよい（画面を開くと `I0001` のように自動で振られる）。振られた後は変えない | `I0001` |
| 発注先 | 発注先マスタの名前と同じ文字 | `○○医療器` |
| 区分 | 発注画面のタブ、発注集計の小計の単位 | `注射薬`、`中材` |
| 小区分 | 区分の中の見出し（置き場など）。空欄でもよい | `ROOM1 針置き` |
| 商品コード | 任意 | `1042881` |
| 品名／メーカー／規格／入数 | 発注画面と発注書に出る | |
| 薬価 | 任意（発注集計に出る） | `146272` |
| 納入価 | 1単位の価格。数量×納入価が発注金額になる（発注のときに単価を変えることもできる） | `129450` |
| 後発 | 後発品なら ☑ | |
| 有効 | 外すと発注画面から消える | ☑ |

品目は行を消さずに「有効」を外して止めてください。発注のときの品名・単価は発注台帳に記録されるので、あとで品目マスタを変えても過去の発注は変わりません。

### 設定

| 項目 | 内容 |
|---|---|
| 施設名 | 画面上部と出力ファイル（収益表・発注書）に表示（空欄でも可） |
| カレンダーID | 入れると、登録・変更・取消が Googleカレンダーにも終日予定として反映される。空欄なら反映しない。使う人がそのカレンダーの「予定の変更」権限を持っている必要がある |

### 管理者設定（管理者用スプレッドシート）

| 項目 | 内容 |
|---|---|
| 入院1人あたり収入(円) | 収益表の「入院」の1人あたり収入 |

### 直接編集しないシート

- **手術・入院台帳**、**発注台帳**：記録の本体。登録・変更・取消は画面から行ってください（直接書き換えると、ベッドの重複確認や変更履歴が働きません）。スタッフが画面から書き込むため保護していません。
- **変更履歴**：誰がいつ何をしたかの記録。

## 開発メモ

- 編集するのは `src/` のファイルです。編集したら `node tools/build-gas.mjs` で `gas/Code.gs` を作り直し、両方をコミットしてください（`node tools/build-gas.mjs --check` でずれを確認できます）。
- `TZ=Asia/Tokyo node test/run-tests.cjs` で、Apps Script のモック上でサーバ側の動作を確認できます（架空のデータを使います）。
- Excel 出力は、一時的にスプレッドシートを作って書き込み、xlsx に変換してから一時ファイルをゴミ箱に移しています。

## 注意

このリポジトリにはコードだけを置きます。患者IDなどの実データ、施設固有の品目・単価の一覧（スプレッドシートの中身）はコミットしないでください。

個人の Google アカウントで運用する場合も、記録するのは患者IDまでにして、氏名などは入れないでください。院内の情報管理規程に沿っているか、事前に確認してください。
